# 100ciencias — instrucciones para Claude

- Antes de crear o cambiar contenido de un tema, sigue **NORMA-LECCIONES.md** (lecciones, escenas vivas, grados,
  «cada idea en un solo lugar», minijuegos). Si un tema necesita otra forma, propónla y anótala en «Excepciones».
- Laboratorios virtuales: toda práctica nueva o convertida sigue la regla «como Tinciones» (mesa viva, pasos reales
  a mano, tiempo real, MicroscopioPanel) de **PLAN-LABORATORIOS.md**, que también tiene la lista de las que faltan.
- El estado del proyecto y las decisiones están en **NOTAS.md**.
- Comprobar siempre con `npm run check:data` y `npm run build` antes de subir.
- JuanMed cuida su límite de tokens: evita trabajo y verificaciones innecesarias.
